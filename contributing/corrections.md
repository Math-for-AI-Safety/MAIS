# Submitting a correction

Typos, broken links, clearer phrasings, missing citations: edit the file directly on GitHub — the pencil icon on any file page opens an editor, and **Propose changes** turns your edit into a pull request, with forks and branches handled invisibly. Merged corrections are acknowledged in the document.

For anything you can't fix in place — a mathematical error, a wrong or misattributed claim, a problem statement that needs repair, a prior resolution of a problem stated as open — [open an issue](https://github.com/Math-for-AI-Safety/MAIS/issues/new/choose) naming the document (by its MAIS identifier if it has one), the exact location, what is wrong, and the fix if you know it. Corrections are credited.

Repairs to a problem's *mathematical content* are conservative by policy: the permanent identifier survives a repair, and a genuinely different problem gets a new identifier rather than silently replacing the old one.
